# Release keystore (committed for open-source reference build)

This keystore is auto-generated for the Islamic Hub reference app. It signs
release APKs so they install cleanly on Android devices.

## Replace with your own keystore for production

1. Generate a new keystore (do NOT reuse this one for production):
   ```bash
   keytool -genkeypair -alias islamichub -keyalg RSA -keysize 2048 \
     -validity 10000 -keystore my-release.keystore \
     -storepass YOUR_STORE_PASS -keypass YOUR_KEY_PASS \
     -dname "CN=Your Name, OU=App, O=Your Org, L=City, ST=State, C=XX" \
     -storetype PKCS12
   ```
2. Replace `islamichub-release.keystore` with your file.
3. Update `keystore.properties` with your credentials.
4. Or set CI env vars:
   - `KEYSTORE_BASE64` (base64-encoded keystore bytes)
   - `STORE_PASSWORD`
   - `KEY_ALIAS`
   - `KEY_PASSWORD`

## CI override

In GitHub Actions, you can set the above env vars as repository secrets. If
set, they take precedence over the committed keystore file.
